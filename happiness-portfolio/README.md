# Happiness Akuma - Portfolio Website

Open `index.html` in any browser. No install or server needed.

## Structure
- `index.html` Home | `about.html` About me | `projects.html` Projects | `planner.html` Academic planner | `contact.html` Contact
- `css/style.css` all styling (responsive, Flexbox/Grid, animations, colour variables at the top)
- `js/main.js` nav toggle, greeting, stats | `js/projects.js` project data + filters | `js/planner.js` task manager | `js/contact.js` form validation
- `images/` headshot and project screenshots | `media/welcome.wav` audio

## Things to personalise
`js/projects.js`.
- Edit your school, skills and hobbies in `about.html`.
- Swap `images/profile.jpeg` to change your photo (keep the same file name).
- Change colours in the `:root` block at the top of `css/style.css`.

## Publishing on GitHub Pages
Upload the folder contents to a repository, then Settings > Pages > deploy from the main branch.
